# INTRODUCTION

## PROJECT DESCRIPTION

The "PAY MASTER" project helps in maintaining the financial transactions/documents in the most efficient and simple manner. This project helps in tracking the progress of different agreement activities of their clients. This project is a good platform for making secure communications for professional activities. Tracking of business related activities is easy and the special feature involved like invoice and managing the expenses from remote locations.

Every company will have its own unique format of submitting the legal documents to the government. This project involves the complete details of the company which includes the establishment, founders/directors, services, the turn over and the basic budget of the company. It includes the personal documents like the PAN card, Aadhaar card and Date of Birth etc.

This project helps in defining user agreements in a most flexible way so that there is complete control of the agreements with the user. This project provides a flexible way where the users can view and filter their agreements according to their clients. This makes the user in tracking the documents easily. This project helps in easy sharing of your documents with their appropriate clients. The clients can upload and download the necessary documents.

This projects helps small or medium enterprises (SMEs) to collaborate with service providers like CAs and CSs. SMEs can easily connect with service providers to bring transparency in communications. It allows both CAs and SMEs to share/request information from each other on click. This system involves the features like managing compliances, collaboration with clients, work management, document management, report generation, configurable alerts to CAs. It allows the SMEs to collaborate with CAs, take control of compliances, role based access, financial document management.
