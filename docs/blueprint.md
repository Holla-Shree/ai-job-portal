# **App Name**: JobMatch AI

## Core Features:

- User Job Portal: User-friendly interface for job seekers to upload resumes, search for jobs, and track applications.
- Recruiter Job Portal: User-friendly interface for recruiters to post jobs.
- AI Job Recommendations: AI-powered job matching that recommends jobs to candidates based on their resume and preferred keywords, powered by an LLM used as a tool to evaluate job requirements.
- Resume Parsing: Resume parsing feature to automatically extract skills and experience from uploaded resumes using NLP techniques. Resume details will be automatically incorporated in the user's profile, and suggested as appropriate for various job opportunities. The AI feature is used as a tool to incorporate relevant data in a generative LLM's output.
- AI Chatbot: AI Chatbot for the job seekers to prepare for interview of the desired job. Chat boat should be able to analyze and correct the answers given by the job seekers for the interview related questions asked by the chat bot. And the bot should be able to suggest the related courses for the seeker to get the desired job.
- Interactive Job Map: Display of job details and search results on interactive maps.

## Style Guidelines:

- Primary color: A moderate blue (#5DADE2) to convey professionalism and trust.
- Background color: Light gray (#F0F2F5) for a clean and modern feel.
- Accent color: A soft green (#A3E4D7) to highlight important elements and CTAs.
- Body font: 'Inter', sans-serif, for a modern, neutral, readable style.
- Headline font: 'Space Grotesk', sans-serif, for headlines, especially where a slightly techy, modern, scientific feel is appropriate.
- Use simple, professional icons related to job categories and industries.
- Clean and intuitive layout with clear sections for job listings, resume uploads, and user profiles.
- Subtle animations for loading states and user interactions.
